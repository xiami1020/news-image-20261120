# Sum up 20 November 2026's world news in one image

make.fun bounty `news-image-20261120` — $250, 50 places, ends 2026-11-22 00:00 UTC.

`main.py` (Python 3.13, stdlib only) copies the bundled `entry.png`
(1024×1024, generated by `generate.py` with Pillow, deterministic)
to `/output/entry.png`. No network, same bytes on every run.

Headlines: Shenzhen trilateral summit (Trump/Xi/Putin, joint peace
declaration); ICJ rules Myanmar committed genocide against the Rohingya;
Anthropic Nasdaq debut +17% to ~$97; Ukraine hits Crimea Bridge a 3rd
time in 4 days; Houthi missile damages Saudi PIF tower in Riyadh;
stocks fall a 5th day, Nikkei -4.8%.
